# simulator radio plugin

The simulator radio plugin `simulator` (RAD-70): a simulated TETRA network
and devices, levels computed from the floor's scene; it drives the demo and
the tour. Shipped in `lib/yantra/plugins/radios/`.

- Documentation: [docs/plugins/simulator.md](../../docs/plugins/simulator.md).
- Tests: `tests/radio/simulator/` (label `plugin:simulator`).
