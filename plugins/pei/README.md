# pei radio plugin

The TETRA terminal plugin `pei` (RAD-80): a terminal's own measurements over
its PEI (AT commands) on a serial port, Linux and Windows; no IQ. Optional
(`YANTRA_RADIOS_PEI`). The simulated terminal for the tests is
`tools/yantra-pei-sim`.

- Documentation: [docs/plugins/pei.md](../../docs/plugins/pei.md).
- Tests: `tests/radio/pei/` (label `plugin:pei`).
