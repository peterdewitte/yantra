# tetra technology plugin

Yantra's TETRA technology plugin (plugin.h, PLG-01): TETRA record schemas,
bands, C1 and reselection rules, the coverage rules and texts. Shipped in
`lib/yantra/plugins/`.

- Documentation: [docs/PLUGINS.md](../../docs/PLUGINS.md).
- Tests: `tests/tetra/` (label `plugin:tetra`).
