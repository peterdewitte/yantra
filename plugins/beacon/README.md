# beacon example technology plugin

`example_beacon`, the example technology plugin of the plugin API tutorial
(plugin.h, PLG-15): built into `lib/yantra/examples/`, never installed; the
plugin template installed with the kit is made from it.

- Documentation: [docs/PLUGINS.md](../../docs/PLUGINS.md).
- Tests: `tests/plugin_loader/test_example_beacon.cpp`, `tests/plugin_kit/` (with its `testdata/`).
