# example radio plugin (beacon)

`beacon`, the example radio plugin of the radio API tutorial (RAD-64): a
made-up beacon signal generated, demodulated and decoded in one plugin.
An example only: built next to the test plugins, never installed.

- Documentation: [docs/RADIO_PLUGINS.md](../../docs/RADIO_PLUGINS.md).
- Tests: the conformance kit (`conformance_beacon`, `tests/radio/radio_host_kit/`) and `doc_snippets_radio` (label `plugin:example`).
