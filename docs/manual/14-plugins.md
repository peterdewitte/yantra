# 14 Plugins

Technologies, radios and extra features are plugins.

## 14.1 The plugin manager

File > Settings > Plugins lists every plugin with its version, licence and state. A plugin switched off stays installed and keeps its settings.

## 14.2 Plugin windows

Plugins can add windows and menu entries; they follow the app's theme, touch layout, language and help rules.
