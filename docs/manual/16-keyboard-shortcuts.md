# 16 Keyboard shortcuts

Tooltips show a control's shortcut in brackets, for example "[Ctrl+S]".

Everywhere:

- Ctrl+N new project, Ctrl+O open, Ctrl+S save, Ctrl+Shift+S save as, Ctrl+W close the project, Ctrl+Q exit.
- Ctrl+, settings.
- F1 the help of the window in front; Esc closes the help.

Editing walls and antennas (Edit page, 13.3):

- P pan, S select, W draw wall, A place antenna.
- While drawing a wall: Enter ends it, Backspace removes the last corner, Esc drops it.
- Delete removes the selected wall, corner or antenna.
- Ctrl+Z undo, Ctrl+Y redo.

Plan import window (13.2): while drawing a polygon, Enter closes it, Backspace removes the last point, Esc cancels it.

Mouse survey (7.1): Esc stops the survey.

On the plan: drag pans (middle or right drag while a tool or a walk uses the left button), the mouse wheel zooms; when no tool uses it, a double click fits the plan to the window.
