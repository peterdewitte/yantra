# 16 Keyboard shortcuts

Ctrl+N new project, Ctrl+O open, Ctrl+S save, Ctrl+Shift+S save as, Ctrl+W close, Ctrl+Q exit, Ctrl+, settings, F1 help of the window in front. Tooltips show a control's shortcut in brackets.
