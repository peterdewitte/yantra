# Yantra: Schnellstart

Kurze Schritt-für-Schritt-Anleitungen, je eine Seite. Das [Benutzerhandbuch](../../manual/README.md) (englisch) beschreibt jeden Schritt im Detail. Diese Übersetzung beruht auf den [englischen Schnellstarts](../README.md); im Zweifel gilt der englische Text.

1. [Erstes Innenprojekt](01-first-indoor-project.md): Grundriss importieren, Etagen zuschneiden, begehen, Bericht.
2. [Innen-Begehungstest mit Abnahmebericht](02-walk-test-acceptance.md).
3. [Einen Empfänger kalibrieren](03-calibrate-a-radio.md).

Jede Anleitung funktioniert mit dem Simulator „Demo (simulated network)“, wenn kein Empfänger zur Hand ist; die Ergebnisse sind dann als simuliert gekennzeichnet.
