# Yantra quick starts

Short step-by-step guides, one page each. The [user manual](../manual/README.md) has the details behind every step.

1. [First indoor project](01-first-indoor-project.md): import a plan, trim the floors, walk, report.
2. [Indoor walk test with acceptance report](02-walk-test-acceptance.md).
3. [Calibrate a radio](03-calibrate-a-radio.md).

Translations (DOC-06): [Nederlands](nl/README.md), [Français](fr/README.md), [Deutsch](de/README.md). Help > Quick starts shows the one of the app's language.

Each guide works with the simulator "Demo (simulated network)" when you have no radio at hand; the results are then marked simulated.
