# Yantra logo

Yantra's own logo (BRD-05..07): a floor plan with a walk-test route
coloured by signal level, a map pin and a radio transmitter, on a teal
rounded square.

| File | Use |
|---|---|
| `yantra_logo.svg` | Master: rounded-square app icon, 512 x 512 viewBox |
| `yantra_logo_square.svg` | Full-bleed square, for avatars that the platform crops |
| `yantra_glyph.svg` | The drawing alone on a transparent background, for dark or teal backgrounds |
| `png/yantra_logo_{16,24,32,48,64,128,256,512,1024}.png` | App, window and desktop icons (stb_image, hicolor icon theme; BRD-06) |

The files are used as supplied: they are never redrawn, recoloured or
re-rendered in this repository (BRD-05).

curtat.be logo in `data/branding/` (BRD-04), forks may keep it.
