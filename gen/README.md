# TETRA test-signal generator

The library of the TETRA test-signal generator (`yantra::gen`, RAD-74):
bursts, cells, the channel model and scenarios. The program is
`tools/yantra-gen`, its scenarios are in `data/scenarios`.

- Documentation: [docs/YANTRA_GEN.md](../docs/YANTRA_GEN.md), [docs/SCENARIO_FORMAT.md](../docs/SCENARIO_FORMAT.md).
- Tests: `tests/radio/gen/`, `tests/radio/gen_sim/`, `tests/radio/gen_osmo/`, `tests/radio/yantra_gen/` (label `gen`).
